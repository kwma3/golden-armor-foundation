# Golden Armor Foundation Website

A modern, responsive website for the Golden Armor Foundation, designed to showcase their mission of empowerment, protection, and healing.

## About

The Golden Armor Foundation envisions a world where every person has the strength, support, and opportunity to rise beyond circumstance. This website serves as their digital presence to communicate their mission and impact.

## Structure

- `index.html` - Main landing page with all sections
- `education.html` - Education program details
- `cancer-research.html` - Cancer research program details
- `clean-water.html` - Clean water program details
- `humanitarian-relief.html` - Humanitarian relief program details
- `styles.css` - Main stylesheet
- `script.js` - JavaScript for interactivity

## Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with gold and navy color scheme
- **Interactive Elements**: Smooth scrolling, animations, and form handling
- **Accessibility**: Semantic HTML and keyboard navigation support
- **Performance**: Optimized for fast loading times

## Four Pillars

1. **Education**: Scholarships and educational resources for underserved youth
2. **Cancer Research**: Funding groundbreaking research and patient support
3. **Clean Water**: Building sustainable water wells worldwide
4. **Humanitarian Relief**: Emergency aid and recovery assistance

## Development

To view the website locally:

1. Clone the repository
2. Open `index.html` in a web browser
